# Code of Conduct

## Our standard

Everyone participating in this project — issues, pull requests, code review, discussions, and community channels — is expected to be respectful and professional. We are all here to build good software.

**Expected behavior:**

- Be kind, patient, and constructive; assume good intent.
- Give and receive critique gracefully; focus on the code, not the person.
- Use welcoming and inclusive language.

**Unacceptable behavior:**

- Harassment, discrimination, or personal attacks of any kind.
- Trolling, insulting or derogatory comments, and deliberate intimidation.
- Publishing others' private information without consent.
- Sustained disruption of discussions or community channels.

## Scope

This Code of Conduct applies within all project spaces (repository, issues, pull requests, discussions) and whenever an individual is representing the project or its community in public spaces.

## Enforcement

Maintainers are responsible for clarifying and enforcing these standards and may edit, remove, or reject contributions that violate this Code of Conduct. Repeated or severe violations may result in a temporary or permanent ban from project spaces.
